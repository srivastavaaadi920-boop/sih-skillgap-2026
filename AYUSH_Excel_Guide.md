## 🔧 Advanced Excel Features

### Create Pivot Table
1. Select all data (Ctrl+A)
2. Insert → Pivot Table
3. Drag **Field** to Rows
4. Drag **Skill Name** to Values (Count)
5. See skill count per field

### Create Filter View
1. Select header row
2. Data → Filter
3. Click dropdown arrows to filter by any column

### Count Skills per Field
```excel
=COUNTIF(A:A,"Ayurveda Clinical Practice")
```

### Count by Category
```excel
=COUNTIF(D:D,"TECHNICAL")
=COUNTIF(D:D,"SOFT")
```
